# 合奏ミキサー(iPhoneアプリ版)

演奏動画を重ねて、原曲(音声ファイル or YouTube)と一緒に再生し、ミキサーで音量を整えて書き出すアプリです。

- 演奏動画を写真ライブラリから複数追加(iCloudからのダウンロード進捗も表示)
- 動画ごとに開始位置をずらす(±1 / ±0.1 / ±0.01 秒、「ここから開始」)
- ミキサー:音量・ミュート(M)・ソロ(S)・映像の表示/非表示・マスター音量
- 原曲:音声ファイル、または YouTube のリンク(プレビュー専用・書き出しには入らない)
- 書き出し:完成動画を写真アプリに保存(実時間より速く書き出し)

## iPhone に入れる手順

1. Mac に Xcode(16 以降)を入れる
2. このリポジトリを clone して `ios/EasyCover.xcodeproj` を開く
3. 左の一覧で「EasyCover」→「Signing & Capabilities」→ **Team** で自分の Apple ID(Personal Team)を選ぶ
   - 「Bundle Identifier が使えない」と出たら `com.atsuyakose.EasyCover` の末尾を少し変える
4. iPhone を USB でつなぎ、上部の実行先で自分の iPhone を選ぶ
5. iPhone で **設定 > プライバシーとセキュリティ > デベロッパモード** をオン(再起動あり)
6. Xcode で ▶(Run)
7. 初回は iPhone で **設定 > 一般 > VPNとデバイス管理** から自分の Apple ID を「信頼」

無料の Apple ID の場合、7日ごとに Xcode から入れ直す必要があります。

## 注意

- YouTube の原曲はアプリ内の公式プレーヤーで鳴らすだけで、書き出す動画には入りません
- iPhone では YouTube の音量をアプリから変えられないので、本体の音量ボタンで調整してください
- 埋め込み再生が禁止されている動画(一部の公式MVなど)は使えません
